Prose editing: today vs headed

Today

A paragraph with bold and a link.

Only the green bits are editable. The paragraph gets a comment box.

Headed directional
A paragraph with **bold** and [a link](#prose).

The whole paragraph is one chunk, edited as markdown. A heading is its own chunk; a list is one chunk.

Invariants

  • The HTML file is the only record. Nothing in the browser, no sidecar.
  • A note is <!-- jess: … -->, attached to exactly one element.
  • Formatting is idempotent: a normalized file loads unchanged.
  • An edit never loses markup.
  • A stale tab cannot write (version check, 409).
  • Dependencies point down: orchestration → domain → interface.

Terms

note
An HTML comment starting <author>:. The human's request to the agent.
normalize
The formatter. Rewrites the file into canonical shape, adding html/head/body if missing.
data-n
Element ID today: document-order index, stamped on serve, stripped on save.
text element
Today's unit of editing: an element whose children are only text.
prose chunk directional
Tomorrow's unit of editing: a phrasing element whose children can all be converted to markdown.
phrasing content
HTML-spec term: text plus inline markup (b, a, code…).
