Element identity is split: assignIds in formatter.mjs mints IDs, reconcile in scopes.mjs keeps them across a rewrite, elementById and baseOf in server.mjs find and check them. reconcile(prior, nodes) never looks at markdown; it pairs old elements with their replacements, so any subtree rewrite could use it. carryDirectives is directive placement and belongs beside the placement rule in directives.mjs. After the move, scopes.mjs is only the markdown language. Mind the formatter/scopes/directives import cycle (CLAUDE.md gotcha). Decisions are in SCOPES-DESIGN.html's Decided table, identity section.
