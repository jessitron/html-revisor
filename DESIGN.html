html-revisor: design

Everything html-revisor adds to a page, drawn with the real stylesheet. This page links client.css; change the stylesheet and both the tool and this page change.

Imperatives

  1. Distinct from the page it revises. The page can be any colors and any styling.
  2. Consistent with itself, so people can always tell which UI came from html-revisor.
  3. Clear what is happening.

Decisions

Decided

(direction): decided, not built yet.

  • Distinct by form, not color. Any color clashes with some page. A shape and material that never change hold up on all of them.
  • The tool draws over the page and never styles it. Hover, selection, and directive marks are elements in the layer, placed over their target. Page elements get no classes. The one rule that reaches them is the copy cursor.
  • One material for every component: near-black surface, 1px light ring, shadow, square corners, the same in light and dark mode. Agent-made pages round their corners; square ones read as not from this page. (direction)
  • The accent is magenta, the revisor's red pencil. It colors the icon, the marks, and the main action.
  • An icon appears in every UI element html-revisor adds. (direction)
  • Crop marks show hover and selection: four corners with the halo, thin on hover, heavier while the element's box is open. Square corners. They never touch the text.
  • No stripe. The marker says the element has a directive.
  • The directive box opens beside its element, never over it, and points at it. Placement is chosen at runtime: below, above, or in the margin when there is room. Phones count. (direction)
  • Markers sit where they don't cover what they mark, in SVG diagrams too. Hovering one shows crop marks on its element and the directive in our own tooltip. (direction)
  • The box's words are true: Done, not Save, since typing saves; "saved" in the box's footer; a quieter Delete; a header with the icon and the element. (direction)
  • The Text field shows the element's own font. Once it holds markdown, monospace. (direction)
  • The pill: bottom right, in the tool's material, with the icon. It counts the directives, steps through them, and holds the stale-file warning. Later, it turns review mode off. (direction)
  • The popup is the directive box. On a text element, it is a directive box with editor: the editor is the field for the element's text.

Not decided

Everything below this section is today's prototype. Where it disagrees with Decided, Decided wins.

  • What the icon looks like.
  • The rules that place the box and the markers.
  • Fonts, sizes, and spacing inside the box.

What it shows. The halo keeps the marker and the crop marks visible on every ground. On our pink, the white edge carries the corners; on the armadillo, the dark edge keeps them off the pale scales. The page element is never restyled, so the tile looks the same with or without the marks. The stripe failed here before it was dropped: it drew over the first letter, disappeared on pink, couldn't show on an image, and next to a page's own pink border it read as part of the page. The marker already says "this element has a directive". Still open: the marker covers the top-left crop mark.

On the page

The tool draws in its own layer above the page and puts no classes on page elements.

Hovering an element puts crop marks at its corners, and the cursor becomes a copy cursor: click to leave a directive or to edit the text.

.hrv-crop: four 10px corners, 2px thick, --hrv-crop-gap (4px) outside the element's box, with the halo. Each arm is at most 30% of its side, so a small SVG label still shows four corners. .hrv-selected, while the box is open: 16px corners, 3px thick, and a 1px outline.

Directive box

Opens 20px below the element's top, 320px wide or the viewport less 16px. Saves 0.4 s after typing stops; Save and ⌘↵ close it.

Icon

Marks everything html-revisor adds to a page. Recommendation: B, and make the marker the same icon, so a pink circle with a pencil always means html-revisor. Pick one; the placements below use B, the .hrv-icon in client.css.

A, today's marker: the ✎ glyph. Its shape depends on the font on each machine.

B, an SVG pencil. Same everywhere; reads as "edit".

C, the proofreader's caret, ‸ "insert here": a revisor's mark. Risk: in a circle it looks like a scroll-to-top button.

Toast

Bottom right of the window. Fades in; leaves after 1.5 s, or 4 s for an error. The stale-file toast stays.

save failed: Failed to fetch
file changed on disk — reload to see it (your unsaved text is in the box)

Type

Everything in the layer: --hrv-font, 13px system-ui at line height 1.4. Labels and the hint: --hrv-small, 11px, muted.
