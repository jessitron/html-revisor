Found during a17m (2026-10-12). Only scopes, hr and svg parts get data-hrv. A directive an agent or a hand edit put on a <b>, <span>, <code> (or anywhere else without an ID) stays in the file, and the agent still sees it with grep, but collectDirectives skips it, so the tab shows no marker and the human can't edit or delete it. Options: the formatter moves it to the nearest element with an ID, or a validation rule reports it. Before a17m every element took directives, so pages written then may have some.
