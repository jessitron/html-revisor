Jess, 2026-10-17: an agent could watch server output and start work while she works. No agent instructions for it yet; make it possible.

Domain words:
- Closing the box is Done (the button's name). Done triggers an Announcement: the server prints what the box session changed.
- A changed Content is a revision. A directive is not a revision; it becomes one when the agent acts on it. An Announcement carries a revision, a directive, or both.

Decided:
- Typing keeps saving as she types (Revert covers a change of mind). Done only decides when the server announces.
- The server never hears a close today. The client sends one on Done (every close path: Done, esc, cmd-enter, click away, open other), with the scope's ID and its markdown and directive from when the box opened. The server reads now from disk, compares, prints. Server stays stateless.
- Nothing changed: no Announcement.
- Reload or tab close with the box open: the changes are on disk, no Announcement. Fine.
- The Announcement is about the scope, by the ID holding it now (a markdown save can move the ID).
- Proposed format: one JSON line per Announcement on stdout (page, data-hrv ID, element description, markdown before/after, directive before/after). It joins the README Contract table. The per-save lines go.
- Layers: Done route is Tier I, comparing before/after into an Announcement is Tier II, stdout is a Tier III adapter.
