What is a prose chunk?

Cases for PLAN.html stage 2. A chunk is the unit of editing and directives: you click it, leave a directive on it, and edit its text as markdown. Each case has the same four parts: its name, the question it asks in grey, the example HTML in a dashed box, and a table of the chunks the example would make. Disagree with a row? Leave a directive on it.

Under each example, chunks.mjs proposes its chunks: one row per chunk, nested rows inside a container. The third column is the markdown the edit box would show. Outlines: prose, blank, code, nonprose, container, run (no outline: no element). ⟦svg⟧ marks nonprose riding inside prose.
