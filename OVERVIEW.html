Invariants

  • The HTML file is the only record: no database, no file beside it, nothing kept in the browser.
  • A directive is <!-- @AI: … -->, attached to exactly one element.
  • Formatting is idempotent: a normalized file loads unchanged.
  • A save can't overwrite an element its tab didn't see (conflict check).
  • An element ID never changes and is never reused.
  • Dependencies point down: orchestration → domain → interface.

Terms

directive
A request from the human to the agent, stored as an HTML comment starting @AI:. Avoid: note, comment, annotation.
Done
Closing the directive box, by its button or any other way. Done triggers an Announcement.
Announcement
What one box session changed, printed by the server as a line of JSON. See compare.
revision
Changed content. A directive becomes a revision when the agent acts on it.
normalize
Rewrite the file into canonical shape. See parse, normalize.
element ID
How the browser and server name an element: data-hrv, written into the file by assign IDs.
scope
The unit of editing and directives: any block you pick, plus links, images, and spans, edited as markdown as a whole. Scopes nest.
Contract
What iterate-on-docs relies on, words included: the table in README. See how it reaches you.
deploy, release
Deploy copies main into iterate-on-docs. Release, run there, versions and publishes it. A deploy is not a release.
phrasing content
HTML-spec term: text plus inline markup (b, a, code…). See MDN: content categories.
