html-revisor: design

Everything html-revisor adds to a page, drawn with the real stylesheet. This page links client.css; change the stylesheet and both the tool and this page change.

Imperatives

  1. Distinct from the page it revises. The page can be any colors and any styling.
  2. Consistent with itself, so people can always tell which UI came from html-revisor.
  3. Clear what is happening.

Decisions

Decided

  • An icon appears in every UI element html-revisor adds.

Not decided

Everything below this section is a prototype, not a deliberate choice.

  • What the icon looks like.
  • Colors. All of them are arbitrary choices so far.
  • How a hovered element looks. The halo helped in the stress test.
  • How the popup looks, and its name.
  • Fonts, borders, sizes: everything else.

A name for the popup. The code says "directive box", but it edits text too, so "directive" undersells it.

  • slip: an editor's slip pinned to a manuscript page. Short, and no page has one. Recommended.
  • card: plain, but the pages we revise have cards of their own, so "the card" is ambiguous.
  • editor: says what it does; collides with the text editor you'd open the file in.

Stress test: any page

Imperative 1. Color alone can't be distinct from every page: some page uses our pink. So every mark gets a halo, a white ring and a dark shadow: a light edge and a dark edge whatever the page.

What it shows. The halo keeps the marker and the hover outline visible on every ground. The stripe fails: it draws over the first letter, disappears on pink, can't show on an image, and next to a page's own pink border it reads as part of the page. Recommendation: rethink or drop the stripe, since the marker already says "this element has a directive".

On the page

The tool puts two classes on page elements. Everything else lives in its own layer above the page.

Hovering an element outlines it, and the cursor becomes a copy cursor: click to leave a directive or to edit the text.

.hrv-hover: 2px dashed accent outline over a 3px halo.

This paragraph has a directive. It gets a stripe on its left edge, and a marker at its top-left corner.

.hrv-has-directive: 3px inset accent stripe. .hrv-marker: 18px with a 2px halo and a shadow, 9px up and left of the element; its tooltip is the directive.

Directive box

Opens 20px below the element's top, 320px wide or the viewport less 16px. Saves 0.4 s after typing stops; Save and ⌘↵ close it.

Icon

Marks everything html-revisor adds to a page. Recommendation: B, and make the marker the same icon, so a pink circle with a pencil always means html-revisor. Pick one; the placements below use B, the .hrv-icon in client.css.

A, today's marker: the ✎ glyph. Its shape depends on the font on each machine.

B, an SVG pencil. Same everywhere; reads as "edit".

C, the proofreader's caret, ‸ "insert here": a revisor's mark. Risk: in a circle it looks like a scroll-to-top button.

Toast

Bottom right of the window. Fades in; leaves after 1.5 s, or 4 s for an error. The stale-file toast stays.

Type

Everything in the layer: --hrv-font, 13px system-ui at line height 1.4. Labels and the hint: --hrv-small, 11px, muted.
