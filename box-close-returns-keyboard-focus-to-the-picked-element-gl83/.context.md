When the box closes (Done, Esc, Cmd-Enter), focus drops to body, so a keyboard user Tabs from the top of the page. The WAI-ARIA dialog pattern returns focus to what opened it. The picked element is often not focusable (a p, a section), and adding tabindex would put a mark on the page beyond data-hrv-review. Options: focus it only when it's focusable (a link); or tabindex=-1 added and removed around the focus call; or focus the element's marker, if markers become buttons. Follows yak njr2.
