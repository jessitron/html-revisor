A cleanup/export step before publishing a page outside the tool. Pairs with squashing the commits. (Jess, 2026-10-12)

Decided (Jess, 2026-10-12): only the agent reads a page's source; people read the rendered page. So the cleanup removes what the tool leaves behind and leaves the formatting alone. It does not reverse the formatter. Indentation, single-line inline runs, single-line SVG, decoded entities, and attribute quoting stay as the formatter wrote them.

Strip:
- directives (<!-- @AI: ... --> comments). Match the way the tool does ('<!-- *@AI:'), not a bare '@AI:', since pages can talk about directives.
- element IDs written into the file. Their shape comes from "Redesign element IDing", hence the blocker.
