Gotchas

  • A test's server.close(cb) can wait 3 s on a keep-alive socket that a request used just before. Call server.closeAllConnections() beside it. A per-phase timing of one test (when fn ended, when close ended) found it in one run; summing test times would not have.
  • The worktree guard refuses /usr/bin/time -p in a loop. A node script in /tmp that times each test file with execFileSync works.
